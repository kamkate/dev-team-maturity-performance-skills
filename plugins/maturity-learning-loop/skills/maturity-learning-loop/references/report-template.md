## Generation rules

- Use actual values from outcome_log.json. Do not round monetary figures
  to look cleaner — show the true calculation.
- If cost_per_eng_day is not configured, replace monetary column with
  "configure cost_per_eng_day in org-config".
- Always include the disclaimer block. Never omit it.
- List ineffective outcomes. Do not hide them. They are learning data.
- If no outcomes in the period, say so explicitly. Do not generate
  an empty table. Say: "No interventions were evaluated in this period.
  [N] are pending lookback."
- Sort per-team table by eng-days descending.
